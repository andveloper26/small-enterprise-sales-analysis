# Small Enterprise Sales Analysis

## Descripción
Proyecto académico desarrollado para la materia Organización Empresarial de la Tecnicatura Universitaria en Programación (UTN).

El objetivo del proyecto es analizar datos de ventas de una pequeña empresa utilizando Python, GitHub, Jira y Google Colab, aplicando metodologías de trabajo colaborativo y control de versiones.
