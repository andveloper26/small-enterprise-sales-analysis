# Small Enterprise Sales Analysis

## Descripción

Proyecto académico desarrollado para la materia Organización Empresarial de la Tecnicatura Universitaria en Programación (UTN).

El objetivo del proyecto es analizar datos de ventas de una pequeña empresa utilizando Python, Google Colab, GitHub y Jira, aplicando metodologías de trabajo colaborativo, control de versiones y trazabilidad de tareas.

## Estructura del proyecto

### datos/
Dataset utilizado para el análisis de ventas.

### scripts/
Script principal de procesamiento y análisis de datos.

### resultados/
Gráficos y resultados generados por el análisis.

## Tecnologías utilizadas

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub
- Jira

## Análisis realizado

El proyecto realiza las siguientes tareas:

- Lectura del dataset de ventas.
- Conversión y procesamiento de fechas.
- Cálculo de ventas totales.
- Cálculo del promedio de ventas.
- Agrupación de ventas por mes.
- Generación automática de gráficos estadísticos.

## Reproducibilidad

Para ejecutar el proyecto:

1. Clonar el repositorio.
2. Abrir el entorno en Google Colab.
3. Verificar que el archivo de datos se encuentre dentro de la carpeta datos.
4. Ejecutar el script:

python scripts/analisis_ventas.py

5. Los resultados se almacenarán automáticamente dentro de la carpeta resultados.

## Control de Versiones

El proyecto utiliza GitHub y Jira para garantizar la trazabilidad entre tareas e implementaciones mediante commits identificados con los IDs de los issues correspondientes.
